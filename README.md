# Soundcer — Downloads

Windows downloads for **Soundcer**, an offline sound library with no limits: search your sounds by name or by describing them in English or Arabic, preview instantly, and drag them into Unity, your DAW or your editor.

**[Download the latest version](https://github.com/abdu-studio/soundcer-releases/releases/latest/download/Soundcer-win-x64.zip)** · Windows 10 / 11, 64-bit

## Install

1. Download `Soundcer-win-x64.zip` from the latest release.
2. Right-click the zip and choose **Extract All** (don't run it from inside the zip).
3. Open the `Soundcer` folder and run `Soundcer.exe`. If Windows shows "Windows protected your PC", click **More info** → **Run anyway** (the app is not code-signed yet).
4. Click **Add folder** and choose your sound folders.

This repository only hosts release files; the source code is private.
